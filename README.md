# Сборки «Рациона»

Здесь лежат готовые сборки приложения и файл, по которому оно узнаёт
о новых версиях. Исходники — в закрытом репозитории; этот открыт потому,
что скачивание из закрытого требует ключа, а зашивать ключ в приложение
нельзя: его достанет любой, кто откроет apk.

| файл | что это |
|---|---|
| `racion.json` | версия, ссылка на сборку и её контрольная сумма |
| `racion-<версия>.apk` | сама сборка, arm64-v8a |

Лежит только последняя сборка: старые приложение всё равно не спрашивает,
а каждая добавленная навсегда прибавляет репозиторию около 22 мегабайт.

## Как приложение это читает

«Анкета» → «Проверить обновление». Приложение скачивает `racion.json`,
сравнивает `versionCode` со своим и, если здесь больше, предлагает поставить.
Сборка качается только по нажатию.

## Установка первой сборки

Скачайте `racion-0.11.apk` с этой страницы и откройте его. Android спросит
разрешение ставить приложения из этого источника — это разовый вопрос.

Дальше обновления идут из самого приложения.

## Подпись

Все сборки подписаны одним постоянным ключом, отпечаток SHA-256:

```
F3:9C:7B:C1:23:77:8D:E0:17:CA:66:4E:D0:BC:83:80:45:62:B8:17:4D:06:9B:7D:8A:87:17:52:FB:4E:95:4D
```

Это и есть защита обновления: Android не поставит поверх сборку, подписанную
другим ключом. Контрольная сумма в `racion.json` лежит рядом со сборкой,
поэтому ловит только обрыв закачки и порчу файла.

## Что здесь не хранится

Ни личных данных, ни ключа подписи. Только приложение для подсчёта калорий.
